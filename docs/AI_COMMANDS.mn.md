# RAINYMINE — локал AI команд гүйцэтгэгч

2026-10-23 · инженерийн туршилтын хувилбар.

## Ашиглах

**Автоматжуулалт → AI команд ажиллуулах** эсвэл баруун туслахын **Программд ажил гүйцэтгэх / Execute application commands** горимыг сонгоно. Асуултаа бичээд Асуух дарна. Тайлсан JSON төлөвлөгөө чатад харагдаж, дэмжсэн команд background-д ажиллана. Энэ горим нь бодит төсөл өөрчилдөг; энгийн зааварт Программын тусламж горим ашиглана.

| Хүсэлт | Бодит үйлдэл |
|---|---|
| `Төслийг шалга` | Төслийн өгөгдлийн validation; засвар зохиож хийхгүй |
| `5 метрээр композит хий` | Эх сорьцыг өөрчлөхгүйгээр point-support композит үүсгэж төсөлд хадгална |
| `5 метрээр композит хийгээд IDW бод` | Ижил композитын уртаар одоогийн блок grid дээр IDW дахин бодно |
| `NN бод`, `OK бод`, `SK бод` | Одоогийн тохируулсан extent/size/search/variogram-ыг ашиглана |
| `QA/QC шалга` | Импортолсон лабораторийн хяналтын үр дүнг дүгнэнэ |
| `Ангиллын санал гарга` | Зөвхөн мэргэжилтний урьдчилан хадгалсан дүрмийг хэрэглэнэ; батлахгүй |

**AI композитын хүснэгт** товчоор бодсон композитуудыг үзнэ. Үнэлгээний үр дүн үндсэн блок модель, 3D болон хүснэгтийг шинэчилнэ. Тохируулсан geometry-тай блокийн байрлал/хэмжээ яг таарах үед density/domain/rock хадгална. Тохиргоо дутуу, geometry зөрүүтэй, эсвэл батлагдсан `resource_class`-тай модель байвал AI-гаар солихыг хориглож гараар хянахыг шаардана. OK-д nugget/partial_sill/range_m, SK-д нэмээд mean-ийг мэргэжилтэн тохируулсан байх ёстой; AI default таахгүй.

## Undo, явц ба цуцлалт

- 1–6 алхмын командын бүх тооцоо тусгаарласан candidate төсөл дээр ажиллана.
- Амжилттай дууссаны дараа нэг удаа хэрэгжүүлнэ. **Ctrl+Z** нэг командын бүх өөрчлөлтийг буцаана, **Ctrl+Y** сэргээнэ. Түүх нь программыг хаах хүртэлх одоогийн bounded Undo budget-тэй; хязгааргүй, дахин нээсний дараах түүх биш.
- Үндсэн дэлгэцийн refresh нь apply үед хийгдэнэ; тооцоо background-д явна. Progress цонхны **Цуцлах** эсвэл туслахын **Зогсоох** товчоор үр дүн хэрэгжихийг цуцална. Тусдаа scientific function цуцлалтыг шалгах хүртэл CPU ажил үргэлжилж болно.
- Хооронд нь төсөл засагдсан бол хуучин үр дүн хэрэгжихгүй. Алдаа, цуцлалт нь эх төслийг өөрчлөхгүй.
- AI candidate хадгалалтын 32 MB хязгаарыг давсан бол apply хийхээс өмнө татгалзана.

## Үйлдлийн бүртгэл

**AI үйлдлийн бүртгэл / AI action history** товч сүүлийн 200 event-ийг харуулна. Windows дээр `%LOCALAPPDATA%/Rainymine/audit/ai-commands.jsonl`, бусад системд `~/.local/share/Rainymine/audit/ai-commands.jsonl` файлд append хийж, дискэнд flush/fsync хийнэ. Requested, started, prepared, completed, failed, cancelled, stale, undo/redo төлөвүүд бүртгэгдэнэ. Асуулт, төлөвлөгөө, командын ID, UTC огноо зөвхөн локал хадгалагдана. Audit нь Undo snapshot-оос тусдаа тул Undo хийхэд арилахгүй. Төслийн дотор мөн сүүлийн 50 командын товч receipt хадгална.

Audit бичих боломжгүй бол эхний өөрчлөлтийг эхлүүлэхгүй. Apply-ийн дараах event бичихэд алдаа гарвал чатад ил тод мэдээлнэ. Локал файл нь tamper-proof серверийн бүртгэл биш; raw assay өгөгдөл бүтнээр audit-д хуулахгүй.

## Локал модель ба эрхийн хил

Тодорхой жишээ командууд deterministic parser-аар модельгүй ч offline ажиллана. Чөлөөт хэлбэрийн хүсэлтэд суулгасан llama.cpp/GGUF локал модель JSON command plan гаргана. Prompt-д эх ордын датаг багтаахгүй; cloud API дуудахгүй. Local engine/model-ийн анхны таталт интернэт шаардаж болно; суулгасан файлуудтай үед ажиллагаа offline.

Allowlist: `validate_project`, `composite`, `estimate_blocks`, `qaqc_summary`, `classification_proposal`. Талбар, төрөл, тоо, параметр бүрийг validator шалгана. Дурын Python/SQL/shell, файл устгах, licensing, network, resource approval, save/export/import команд AI-д өгөөгүй. Ангиллын зөвхөн review-pending санал гаргана; A/B/C эсвэл JORC нийцэл батлахгүй. Файл импорт/экспорт болон хэвлэлтийн одоогийн товчнуудыг хэрэглэгч өөрөө ашиглана.

Энэ нь бүх UI-г хулганаар удирддаг autonomous agent биш. Локал LLM тайлсан төлөвлөгөөний утгыг чатад хянаж, өөрчлөлтийг Undo-оор буцааж болно. Чөлөөт Монгол хэлний LLM чанарыг бодит ордын хэрэглэгчээр тусад нь шалгах шаардлагатай.

## Шалгалтын нотолгоо

Linux Python 3.12 / Qt 6.8.3, native Rust/C++ extension-тэй 326 тестийн бүтэн багц амжилттай. Дараагийн засваруудыг UI readability/responsiveness ба AI тооцооллын 28 тест, эцсийн 7 команд/GUI интеграцийн тестээр шалгасан. Үүнд нэг Undo/Redo, source preservation, density/domain хадгалалт, цуцлалт, stale result, error isolation, audit, буруу model tool татгалзах нөхцөлүүд багтсан. Model-plan routing тест нь mock local engine ашигласан; бодит GGUF-ийн чөлөөт Монгол хэлний чанар болон шинэ Windows installer дээрх end-to-end ажиллуулалт энэ шалгалтаар батлагдаагүй.
