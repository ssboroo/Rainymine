# RAINYMINE — өдөр тутмын ашиглах заавар

[README](../README.md) · [Shortcut](SHORTCUTS.mn.md) · [Бүх хэрэгсэл](TOOLS.mn.md)

## 1. Төсөл бэлтгэх

Суулгалтын дараа зохиомол жишээ нээгдэнэ. Өөрийн өгөгдөлд Ctrl+N дарж шинэ төсөл үүсгээд нэр, CRS, координатын метр нэгж, агуулгын нэгжээ тохируулна. EPSG мэдэгдэхгүй байхад таамгаар CRS сонгохгүй; эх файлын нийлүүлэгчээс тодруулна. Координатад RTC local origin хэрэглэдэг ч буруу CRS-ийг засахгүй.

Ctrl+Shift+S-ээр ажлын `.rmine`-аа үүсгэнэ. Бүх эх файл, лабораторийн эх тайланг тусад нь хадгална. Хадгалсан dirty төсөл хоёр минут тутам `.rmine.autosave` бичнэ; анх хадгалаагүй төсөлд үүсэхгүй. Сэргээхдээ эх төсөл ба autosave-аа хуулж аваад нөөцийн хуулбарыг `.rmine` өргөтгөлтэй болгож нээн, өөр нэрээр хадгалж шалгана.

## 2. Ердийн CSV / Excel

Амсар → замнал → сорьц → литологи дарааллаар оруулна. Баганы mapping-ийг шалгаж, цооногийн ID, X/Y/Z, эцсийн гүн, азимут/унал, From/To ба агуулгыг тохируулна. Шаардлагатай Structure/Geotech-ийг дараа оруулна. XLSX нь sheet ба баганын сонголттой; formula/error cell, `.xls` / `.xlsm` дэмжихгүй. CRS хөрвүүлэлт шаардвал эх ба зорилтот CRS-ээ ил тод сонгож, мэддэг хяналтын цэгээр шалгана; бүх импорт автоматаар хөрвүүлдэггүй.

Импортын тайлан, давхардсан ID, сөрөг / давсан гүн, From ≥ To, давхцсан интервал, orphan цооног, замналын догол ба assay coverage-ийг шалгана. Editable grid-ийн өөрчлөлтийн дараа validation дахин ажиллуулна. Хоосон агуулга нь 0 биш; QA/QC-ийн blank, standard, duplicate-ийг зөв ангилна. Алдаа байгаа үед үнэлгээний үр дүнгээр эх өгөгдлийг зөв гэж үзэхгүй.

## 3. DH CSV багц

**Мэргэжлийн хэрэгсэл → DH өгөгдөл → DH CSV багц импорт…**-оор collar ба холбоотой файлуудаа хамтад нь сонгоно. Танигдсан `dh_collar.csv`-ийг ердийн CSV импортод сонгоход мөн багцын сонголт руу орно.

Эх хүснэгт, элемент, нэгжийн сувгаа сонгоно. Long/pivot-ийг давхар тоолохгүй. NULL/BDL/LDL/`<limit`-ийг 0 гэж оруулахгүй; half-limit хэрэгтэй бол зориуд сонгоно. Survey файл байхгүй бол амсрын азимут/уналаар **шулуун замналын таамаглал** хэрэглэнэ; бодит downhole survey гэсэн үг биш.

**DH эх хүснэгт / CSV экспорт…** нь файлыг 200 мөрөөр хуудаслаж харуулж, анхны CSV-г яг байтаар нь гаргана. Raw хүснэгт засварлахгүй. **DH сорьцын элемент солих…** нь scientific төслийг дахин байгуулж хуучин блок / геометрийг цэвэрлэдэг тул эхлээд өөр нэрээр нөөцөлнө. [Файлын нэр, qualifier, архивын хэмжээ, CRS-ийн бүрэн дүрэм](DH_IMPORT.mn.md).

## 4. Харагдац, огтлол, хэмжилт

Давхаргын checkbox-оор харагдах эсэхийг, Properties-оор өнгө, opacity, solid/wireframe/points-ийг тохируулна. Цооногийн нэрээр хайж, хүснэгт эсвэл 3D-ээс сонгоно. Блокийн мөр сонгоход баруун талд координат, агуулга, нягт, домэйн, хэмжээ харагдана. Хоосон утга автоматаар зохиогдохгүй.

Огтлолын чиглэл, байрлал, slab-ийн зузаан / алхмыг тохируулж PageUp/PageDown-оор шилжинэ. Нэртэй огтлол хадгалж дахин нээж болно. Cutaway, slab, cutoff нь харагдацад нөлөөлөх тул source block устсан гэж ойлгохгүй. Хэмжих горимд объект дээрх хоёр цэгийг дарна. [Камер, гар ба хулганы удирдлага](SHORTCUTS.mn.md).

## 5. Загварчлал ба үнэлгээ

Эхлээд string/polygon, TIN эсвэл domain геометрээ шалгана. Solid-д manifold/watertight шалгалт хэрэглэнэ. RBF-ийн хүрээ, support, анизотроп ба хагарлын таамаглалыг тохируулна; гадарга гарсан нь геологийн зөв битүү solid гэсэн баталгаа биш.

Композитын урт, top-cut, нягт, домэйн, блокийн хэмжээ / эргэлт, search ellipsoid, хөршийн хязгаар ба үнэлгээний аргаа сонгоно. Variogram, cross-validation, swath ба харааны шалгалтыг хамтад нь хийнэ. Нягтын нэгж т/м³, агуулгын нэгж ба cutoff-оо нийцүүлж тонн–агуулгын тайлан гаргана. Үр дүнг UNCLASSIFIED / мэргэжлийн хяналт шаардлагатай гэж хэрэглэнэ.

[Мэргэжлийн CAD, implicit, stope, ramp, MILP хэрэгслийн нөхцөл](PROFESSIONAL_WORKFLOWS.mn.md) · [SRS инженерийн хэрэгжилт](SRS_V2_ENGINEERING.mn.md).

## 6. Хадгалах ба солилцох

Ажлын бүтэн төслөө `.rmine`-аар хадгална. Зурагт PNG, замнал / хүснэгтэд CSV, геометрт DXF/OBJ/STL ашиглана. CSV–CAD ZIP нь CRS, нэгж, NULL, эргэлт ба hash бүхий manifest дамжуулна. OBJ/STL дангаараа геологийн бүх мэдээллийг хадгалахгүй.

OMF **2.0-beta.1 экспорт л** дэмжинэ. GeoPackage нь сонгосон vector layer-ийн импорт / экспорт; блокийн бүтэн сан биш. Хүлээн авагч программтай CRS, vertical datum, агуулгын нэгж, NULL ба sub-block төрлийг тохирч, жижиг мэдэгдэж буй загвараар round-trip шалгана. [Нээлттэй солилцооны заавар](OPEN_EXCHANGE.mn.md).

## 7. Алдаа засах

| Асуудал | Шалгах / хийх зүйл |
|---|---|
| CSV орохгүй | Ердийн mapping эсвэл DH bundle аль нь болох, encoding, багана, ID, From/To ба импортын тайланг шалгах |
| Объект харагдахгүй | Давхарга, cutoff, slab/cutaway, координат, камерын Төвлөрүүлэх командыг шалгах |
| 3D хар / хоосон | Багцын `Rainymine-Software.bat` эсвэл CPU rendering хувилбараар турших |
| Команд харагдахгүй | Ctrl+K, Ctrl+Shift+P эсвэл ribbon-ийн хэвтээ scrollbar ашиглах |
| Тооцоо удаан | Түүвэр / ROI / хэмжээний хязгаар шалгах; background cancel нь native solver-ийг шууд зогсоохгүй байж болно |
| AI бэлэн биш | Offline багц эсвэл AI бэлтгэх / Файл сонгох; модельгүйгээр шууд зааврын жагсаалтыг унших |
| Хадгалалт амжилтгүй | Бичих эрх, сул диск, `.rmine` 32 MB ба архивын хязгаар шалгах; өөр нэр / хавтас турших |
| SQL холбогдохгүй | ODBC driver, integrated auth, сервер ба canonical views-ийг админтай шалгах |

Асуудал үргэлжилбэл [дэмжлэгийн маягт](../release/SUPPORT_TEMPLATE.mn.md)-д хувилбар/commit, Windows, GPU, алдааны текст, давтах алхам ба нууцлалгүй хамгийн жижиг жишээг бичнэ. [Мэдэгдэж буй хязгаар](../release/KNOWN_ISSUES.mn.md)-ыг давхар үзнэ.
