# RAINYMINE — shortcut ба хулганы удирдлага

[README](../README.md) · [Ашиглах заавар](USER_GUIDE.mn.md) · [Хэрэгслийн жагсаалт](TOOLS.mn.md)

2026-10-22-ны үндсэн desktop кодод бүртгэлтэй **12 shortcut**. Программын үндсэн цонх идэвхтэй үед хэрэглэнэ; modal диалог нээлттэй бол эхлээд дуусгах / хаах шаардлагатай байж болно. Текст засварлах талбарт зарим товч тухайн талбарын үйлдэлд очно.

## Үндсэн цонх

| Товч | Үйлдэл | Тайлбар |
|---|---|---|
| Ctrl+N | Шинэ төсөл | Хадгалаагүй өөрчлөлт байвал хадгалах эсэхийг асууна |
| Ctrl+O | Төсөл нээх | `.rmine` файл сонгоно; CSV импортын shortcut биш |
| Ctrl+S | Хадгалах | Анхны удаа файл сонгох диалог нээгдэнэ |
| Ctrl+Shift+S | Өөрөөр хадгалах | Шинэ нэр / байршилтай хуулбар хадгална |
| Ctrl+Z | Буцаах | Төслийн өөрчлөлтийн history; бүх камер / самбарын үйлдэл history-д орохгүй |
| Ctrl+Y | Сэргээх | Буцаасан төслийн өөрчлөлтийг сэргээнэ |
| Ctrl+K | Үйлдэл хайх | Ribbon ба цэсийн командуудаас хайна |
| Ctrl+Shift+P | Бүх хэрэгсэл | Хэрэгслийн санг нээнэ |
| Ctrl+F1 | Ribbon хураах / дэлгэх | 3D талбайн зайг нэмэгдүүлнэ; табыг давхар дарж мөн сольж болно |
| F10 | Төвлөрсөн горим | Давхарга, туслах, хүснэгт, ribbon-ийг нуух / өмнөх харагдацыг сэргээх |
| PageUp | Өмнөх огтлол | Огтлолын одоогийн алхмаар шилжинэ |
| PageDown | Дараах огтлол | Огтлолын одоогийн алхмаар шилжинэ |

Зарим зөөврийн гар дээр F1/F10/PageUp/PageDown-д **Fn** давхар дарах шаардлагатай; энэ нь төхөөрөмжийн тохиргоо.

## Хайлт, диалог ба бичвэр

| Байршил | Товч | Үйлдэл |
|---|---|---|
| Ctrl+K командын хайлтын талбар | Enter | Одоогийн үр дүнг ажиллуулах |
| Ctrl+K командын хайлтын талбар | ↓ | Үр дүнгийн жагсаалтад focus шилжүүлэх |
| Үр дүнгийн жагсаалт | ↑ / ↓, Enter | Сонголт шилжүүлэх, ажиллуулах |
| Ердийн диалог | Tab / Shift+Tab | Дараах / өмнөх удирдлагад шилжих |
| Ердийн цуцалж болох диалог | Esc | Диалог цуцлах; удаан native solver-ийг заавал шууд таслахгүй |
| Засварлах бичвэрийн талбар | Ctrl+A / Ctrl+C / Ctrl+V / Ctrl+X | Тухайн талбарын сонгох / хуулах / буулгах / таслах |
| Локал туслахын асуултын талбар | Enter | Асуулт илгээх |

Эдгээр нь тухайн widget-ийн удирдлага. **Ctrl+C/V нь уурхайн объект хуулах / буулгах глобал команд биш.** Бүртгэлгүй CAD shortcut, F1 help, Delete геометр устгалтыг таамгаар бүү хэрэглэ; хэрэгслийг цэс эсвэл Ctrl+K-ээр сонгоно.

## 3D талбар

| Оролт | Үйлдэл |
|---|---|
| Зүүн товчийг чирэх | Камер эргүүлэх |
| Shift + зүүн товчийг чирэх | Камер зөөх |
| Хулганы дугуй | Томруулах / багасгах |
| Зүүн товчоор объект дээр дарах | Сонгох горимд цооног / блокийг хүснэгт, шинж чанартай холбох |
| Хэмжих горимд хоёр цэг дарах | 3D зай ба өндрийн зөрүү хэмжих; объектын сонголт өөрчлөхгүй |
| Хүснэгтийн мөр сонгох | Холбогдсон объектын мэдээлэл харах |

Камер алдагдвал **Төвлөрүүлэх**, **3D**, **Төлөвлөгөө** зэрэг харагдацын хэрэгслийг ашиглана. Давхарга нуугдсан, slab/cutaway идэвхтэй эсвэл cutoff өндөр байвал объект сонгогдохгүй байж болно. Gizmo нь тусдаа хэрэгсэл: өөрчлөлтийг **Apply**, татгалзахыг **Cancel**-аар шийднэ.

## Жижиг дэлгэц

Ribbon-ийн доод хэвтээ scrollbar-ыг чирж захын командыг харуулна. Хүснэгтийг мөн хэвтээ гүйлгэж, баганын заагийг чирж өргөнийг өөрчилнө. Бүтэн нэрийг tooltip-оос харна. Блок сонгоход баруун шинж чанар дэлгэгдэнэ; самбарын гарчгаар эвхэж болно. Windows 150% / 200% scaling-ийн автомат layout шалгалт бий; бодит дэлгэц дээр readability-г мөн шалгана.

## Кодтой тулгах

Файл: `rainymine/ui.py` (төсөл), `workbench.py` (history), `navigation.py` (огтлол), `workspace.py` (самбар / хайлт), `presentation.py` (командын хайлтын диалог). `presentation.py`-ийн хуучин цонхны давхардсан bindings-ийг нэмэлт shortcut гэж тоолоогүй.
