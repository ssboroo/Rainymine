# RAINYMINE 1.0.0-rc.1

Энэ нь v1.0-ийн release candidate. Micromine-ийн бүрэн орлуулалт, native DAT нийцэл, нөөцийн ангиллын баталгаа эсвэл бүх төхөөрөмжийн SLA гэсэн мэдэгдэл биш. [Одоогийн release config](../release/config.json) нь draft/prerelease, үйлдвэрлэлийн шалгалт дутуу гэдгийг хэвээр тэмдэглэнэ.

## Бүтэн төслөө зөөх

**Мэргэжлийн хэрэгсэл → Төслийн багц → Төслийн бүрэн багц хадгалах…**

`.rmpack` нь `.rmine` доторх өгөгдөл болон workspace-д холбоотой `.rmdb` сангуудыг нэг ZIP-д хадгална. SQLite Backup API-аар сан бүрийн тогтвортой snapshot үүсгэнэ; undo/redo түүх нь багтана. Эх сан өөрчлөгдөхгүй. Олон сангийн snapshot нь тус тусдаа; бүх санг хамарсан нэг зэрэг transaction биш.

**Төслийн багц сэргээх…** → багц сонгох → эх хавтас → шинээр үүсгэх хавтасны нэр. Архивын SHA256, хэмжээ, файлын жагсаалт, SQLite integrity, CRS/нэгжийг шалгаж байж шинэ хавтас үүсгэнэ. `project.rmine`-ийн холбоосууд шинэ `.rmdb` зам руу өөрчлөгдөнө. Өмнө байгаа хавтас дээр сэргээхгүй. Алдаа / cancellation үед түр хавтсыг цэвэрлэнэ, өмнөх багцыг солихгүй.

Хязгаар: 32 холбоотой сан, задарсан нийт хэмжээ 5 GB, үндсэн `.rmine` 32 MB. Түр snapshot болон ZIP-д нэмэлт сул диск хэрэгтэй. SHA256 нь эвдрэл шалгана; үйлдвэрлэгчийн тоон гарын үсэг биш. Сангийн гаднах бусад arbitrary файл, зураг/документын замыг автоматаар цуглуулахгүй. Төслийн геометр ба DH raw archive нь `.rmine`-д багтсан хэмжээгээрээ зөөгдөнө. Түүхэн run metadata дахь хуучин замууд provenance хэвээр; идэвхтэй disk_block_stores холбоосыг л дахин байрлуулна.

## Өгөгдөл алдалгүй блок импортлох

**Блок өгөгдөл → Micromine / CSV блок импорт…**

- XYZ төв, DX/DY/DZ, нэг grade баганыг сонгоно. Эргэлттэй / sub-block-д explicit parent origin/size ба RAINYMINE ENU өнцөг хэрэглэнэ; vendor Euler metadata автоматаар хөрвөхгүй.
- Нягтын багана сонговол t/m³ тоон утга, домэйны багана сонговол text гэж уншина. Автомат нэгжийн хөрвүүлэлт хийхгүй.
- Бусад баганыг **Текстээр хадгалах** сонголт нь эх нэрийг `source:` namespace-тай `attributes` дотор хадгална. `0007` гэх ID-г 7 болгохгүй. Text хоосон мөр ба NULL ялгаатай; NULL/NONE/NAN токеныг NULL гэж үзнэ.
- Backend-ийн explicit attribute schema нь number/text/boolean ба нэгж хадгалдаг. Number хоосон утга NULL; Boolean true/false/1/0; тоон infinity татгалзана. GUI-ийн бусад баганууд эх текстээрээ хадгалагдана, автоматаар scientific numerical attribute болохгүй.
- Нэмэлт багана ≤64. Нягт эерэг, хувь grade ≤100 байна. Алдаатай scientific мөрийг чимээгүй алгасахгүй.
- Эх нөөцийн classification утгыг хадгалсан ч model **UNCLASSIFIED** хэвээр; certified classification болохгүй.

Тонн–агуулгын тайлан нь блокийн density байгаа үед түүнийг хэрэглэнэ; NULL/байхгүй үед диалогийн fallback density хэрэглэнэ. `density_t_m3` нь сонгосон блокуудын effective bulk density, `fallback_density_t_m3` нь хэрэглэгчийн fallback. Mean grade нь массаар жигнэгдэнэ. Хуучин density-гүй моделийн тооцоо хэвээр.

## Давтагдах шалгалтын урсгал

1. Импорт → validation/QAQC → grid/geometry хяналт.
2. Grade ба density нэгжээ шалгах → tonnes/grade.
3. Project save/load → `.rmpack` export → өөр шинэ хавтаст restore.
4. `.rmdb` count, grade/density/domain, undo/redo ба тайланг шалгах.
5. Гадаад reference-тэй geometry/grade/density/domain/volume/tonnage харьцуулах. Reference гарал, software version ба инженерийн хяналтыг тусад нь батлах.

Synthetic тест нь 2 × 1000 м³ блок, density 2.5/2.7 т/м³, grade 0/2 ppm-д нийт 5200 т, weighted grade 5400/5200 ppm гэдгийг шалгана. Энэ нь бодит ордын хяналт биш.

## Release ба compatibility

- `.rmine` schema v3 хэвээр; v1/v2 migration хадгалагдана. Программын хувилбар ба төслийн schema version тусдаа.
- Нэг version source: `rainymine.__version__`. `python scripts/release_version.py --check` нь config/tag/artifact нэрсийг тулгана. `--write-installer` нь `dist/Version.iss` үүсгэнэ.
- Суулгагчийн RC нэр `1.0.0-rc.1`, binary version нь `1.0.0.0`; [Inno numeric version дүрэм](https://jrsoftware.org/ishelp/topic_setup_versioninfoversion.htm).
- Windows CI нь source тест, 1M disk workflow benchmark, 150/200% UI, MN/EN smoke, frozen EXE, install/reinstall/uninstall-ийг ажиллуулна. Физик хэрэглэгчийн Windows acceptance тусдаа.
- `build_windows.ps1 -Production` нь owner key, сертификат, зөвшөөрөл, төхөөрөмж/ордын validation дутуу үед зогсоно. Эдгээрийг хийсэн гэж автоматаар тэмдэглэхгүй.

## v1.0 final-д үлдсэн гаднын нотолгоо

Бодит ордын reference ба эрх бүхий инженерийн хяналт; физик Windows/GPU acceptance; owner лицензийн public key, түгээлтийн шийдвэр, Windows signing certificate. Native DAT decoder нь энэ RC-ийн дэмжигдсэн формат биш. Том `.rmdb` нь bounded centre-support IDW / preview урсгал; full-resident 10M/50M 60 FPS баталгаа биш.

[RC-ийн 1M synthetic disk workflow хэмжилт](benchmarks/v1-disk-workflow-1m-linux.json): энэ орчинд grid 1.66 s, IDW 3.02 s, CSV экспорт 2.75 s; process peak RSS ~269 MiB. Warm single run; физик GPU FPS хэмжээгүй.
