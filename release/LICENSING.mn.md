# 7 хоногийн туршилт ба төхөөрөмжийн лиценз

1.0.0-rc.1-д «7 хоногийн туршилтыг эхлүүлэх» дарснаас хойш 168 цагийн offline туршилт эхэлнэ. UTC цагаар тооцно. Шинээр нээх, portable ZIP дахин задлах, программаа дахин суулгах нь хадгалагдсан туршилтын хугацааг сунгахгүй. Windows хэрэглэгч тус бүр өөр төхөөрөмжийн дугаартай.

Хугацаа дуусахад ашиглалтыг идэвхжүүлэх цонхоор хаана. Нээлттэй төслөө хадгалах товч болон хаахын өмнөх хадгалах асуулт хэвээр байна. `.rmine` төслүүд, нөөц хуулбар, экспортолсон файлыг устгахгүй. Нээлттэй сессийн хугацааг 30 секунд тутам дахин шалгана; урт ажиллагааны үед Qt event loop дахин ажиллахад цонх гарна.

## Windows хамгаалалт

Туршилтын төлөвийг Windows DPAPI хэрэглэгчийн хамгаалалтаар `%LOCALAPPDATA%\Rainymine\licensing\trial.dat` болон `HKCU\Software\Rainymine\Licensing`-д хадгална. Нэг хуулбарыг устгахад нөгөөгөөс эхлэх огноог сэргээнэ. Унших/бичих алдаа, эвдэрсэн бүртгэл болон 120 секундээс их цаг ухралт ашиглалтыг түр хаана. Системийн цагаа зөв болгоно; бүртгэлийг гараар устгахыг засварын арга гэж зөвлөхгүй.

Offline local trial нь хамгаалалтыг эвдэх эрхтэй администраторын эсрэг баталгаа биш. Хоёр төлөвийг бүхэлд нь устгах, Windows хэрэглэгч/систем солих, эх код өөрчлөх зэрэг оролдлогыг сервергүйгээр найдвартай хориглохгүй. Арилжааны хүчтэй entitlement, төхөөрөмжийн тоо, revoke, төлбөр, trusted time сервер энэ хувилбарт байхгүй. Linux/source developer орчин DPAPI ашиглахгүй; Windows түгээлтийн хамгаалалттай адил гэж үзэхгүй.

## Лиценз идэвхжүүлэх

«Лиценз → Хугацаа ба идэвхжүүлэлт…» дээрх төхөөрөмжийн дугаарыг эзэмшигчид өгнө. Эзэмшигчийн гарын үсэгтэй `.rainylic` файлыг сонгоно. Программ Ed25519 гарын үсэг, бүтээгдэхүүн, төхөөрөмж, эхлэх/дуусах огноог шалгасны дараа хадгална. Лиценз ба дэмжлэг: **RAINY STUDIO · 90220101**. Лиценз авах URL, төлбөрийн систем, дэмжлэгийн имэйл өгөөгүй.

**Одоогоор арилжааны гарын үсгийн нийтийн түлхүүр тохируулаагүй.** 7 хоногийн туршилт ажиллана; арилжааны хүчинтэй лиценз олгохын өмнө эзэмшигч доорх алхмыг өөрийн хамгаалсан машин дээр хийж, public key-тэй шинэ build гаргана. Нууц түлхүүрийг энэ ажлаар үүсгээгүй, репод оруулаагүй, EXE-д багтаахгүй.

## Эзэмшигчийн хэрэгсэл

Python болон төслийн dependency-тэй хамгаалсан машин дээр:

```powershell
python scripts/license_admin.py init --private-key D:\RainymineOwnerKeys\issuer.pem --public-keys assets/license-public-keys.json --key-id rainy-2026-01
```

Нууц үгийг interactive асууна; private key password-тай шифрлэгдэнэ. Private key-г репо/build хавтаснаас гадна, зөвхөн эзэмшигчийн зөвшөөрөлтэй хадгалж найдвартай нөөцөлнө. Зөвхөн `assets/license-public-keys.json`-ийг commit хийж Windows build дахин үүсгэнэ. Энэ файлд public key л байна. Public key өөрчилсөн бол өмнөх EXE өөрөө өөрчлөгдөхгүй.

```powershell
python scripts/license_admin.py issue --private-key D:\RainymineOwnerKeys\issuer.pem --key-id rainy-2026-01 --customer "Хэрэглэгчийн нэр" --device "программаас хуулсан 64 тэмдэгтийн дугаар" --days 365 --output customer.rainylic
```

Дээрх `365` нь жишээ; үнэ ба гэрээний хугацааг эзэмшигч тогтооно. Файл гарын үсэгтэй боловч нууцлагдаагүй: хэрэглэгчийн нэр, төхөөрөмжийн hash, хугацаа агуулна. Илгээхийн өмнө зөв хүнд хамаарахыг шалгана. Хугацааны сунгалтад шинэ файл олгоно; key rotation хийхдээ хэрэглэгчийн хүчинтэй түлхүүрүүдийг public registry-д хадгална.

Энэ баримт нь техникийн механизмын заавар. Эцсийн ашиглах гэрээ, программын эх кодын лицензийг орлохгүй. Эзэмшигчийн хүссэн эхний шат нь 7 хоногийн нээлттэй туршилт; дараагийн шат нь хаалттай арилжааны түгээлт.
