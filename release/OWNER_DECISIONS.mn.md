# Эзэмшигчийн эцэслэх мэдээлэл

Эдгээрийг программ эсвэл автомат build эзэмшигчийн өмнөөс зохиож батлахгүй.

| Мэдээлэл | Төлөв |
|---|---|
| Эзэмшигчийн өгсөн нийтлэх нэр | RAINY STUDIO |
| Программын өөрийн түгээлтийн лиценз, үнэ, ашиглах нөхцөл | Эцэслэх; шинэ лиценз энэ бэлтгэлээр автоматаар олгоогүй |
| Дэмжлэгийн утас | 90220101 |
| Дэмжлэгийн имэйл/сайт, хариу өгөх нөхцөл | Өгөөгүй; эцэслэх |
| Тоон гарын үсгийн сертификат ба timestamp | Холбогдоогүй |
| Шинэ брэндбүүк/лого/интерфэйсийг бодитоор хэрэгжүүлж батлах | Ажлын талбарын зохион байгуулалт ба вектор тэмдэг хэрэгжсэн; постерын фото/texture/эхлэх дэлгэц концепц хэвээр |
| Бодит төхөөрөмж дээрх acceptance гарын үсэг | Хүлээгдэж буй |
| Бодит ордын хараат бус баталгаажуулалт | Хүлээгдэж буй |

Third-party лицензүүд нь тус бүрийн upstream нөхцөлтэй. Release kit доторх license inventory нь эзэмшигчийн хууль/лицензийн эцсийн хяналтыг орлохгүй.

Эзэмшигчийн сонгосон чиглэл: эхний шатанд 7 хоногийн нээлттэй туршилт, цаашдаа хаалттай арилжааны түгээлт. Энэ нь эх кодод автоматаар нээлттэй лиценз олгохгүй. Арилжааны private key-г эзэмшигч өөрийн хамгаалсан орчинд үүсгэж, public key-тэй build гаргана.
