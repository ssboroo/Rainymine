# RAINYMINE 2026 — 1.0.0-rc.1 туршилтын хувилбар

**Эзэмшигч:** RAINY STUDIO · **Дэмжлэгийн утас:** 90220101

Монгол хэлд төвлөрсөн Windows x64 геологи, уурхайн ажлын программ. Энэ нь туршилтын түгээлт; Micromine-ийн бүрэн орлуулалт, баталгаажсан нөөцийн тайлан эсвэл батлагдсан уурхайн төлөвлөгөө биш.

## v1.0.0 RC1 — 2026-10-22

- Импортын өргөтгөл ба production foundations-ийг нэгтгэсэн.
- `.rmpack`: проект + холбоотой SQLite сангийн backup snapshot, SHA256 manifest, шинэ хавтаст аюулгүй сэргээх, холбоос дахин байрлуулах.
- CSV density/domain mapping, нэмэлт source text attributes ба typed backend schema; блокийн нягтаар жигнэсэн tonnes/grade.
- Version/tag/artifact нэрийн автомат consistency шалгалт, generated Inno binary version.
- [Хэрэглэх заавар ба үлдсэн шалгуур](../docs/V1_0.mn.md). Энэ түгээлт release candidate; independent deposit validation, physical Windows acceptance, production signing/licensing pending хэвээр.

## Өмнөх шинэчлэлтүүд — 2026-10-22

- Бүтэн нэртэй хоёр мөрийн ribbon, хэвтээ гүйлгэх удирдлага, Ө/Ү дэмжих 3D фонт, эвхэгддэг / гүйлгэх блокийн шинж чанар; 150% / 200% layout шалгалт.
- DH CSV bundle, long/pivot элемент ба нэгж сонголт, qualifier / NULL тайлан, portable эх архив, 200 мөрийн raw хүснэгт ба яг эх CSV экспорт.
- OMF 2.0-beta.1 экспорт, GeoPackage vector солилцоо, CRS / нэгж / NULL metadata бүхий CSV–CAD ZIP.
- CAD CSG / gizmo, нэмэлт формат, constrained RBF, IK / multipass, ramp / tunnel / ring, хязгаартай stope / blend MILP ба external preview.
- README, [12 shortcut](../docs/SHORTCUTS.mn.md), [өдөр тутмын заавар](../docs/USER_GUIDE.mn.md), [баримтын индекс](../docs/README.md) шинэчлэгдсэн.

Форматын нарийн хүрээ, scientific ба performance acceptance-ийг [мэргэжлийн урсгал](../docs/PROFESSIONAL_WORKFLOWS.mn.md), [DH](../docs/DH_IMPORT.mn.md), [солилцоо](../docs/OPEN_EXCHANGE.mn.md)-оос шалгана.

## Нэгдсэн main ба брэндинг

Main-ийн эхлэх дэлгэц, нэгтгэсэн вектор icon, Ctrl+K команд хайлт, Ctrl+F1 хэрэгслийн мөр, F10 төвлөрсөн горим, Шошго удирдлагыг хадгалсан. [Брэндбүүк](../docs/BRANDBOOK.mn.md) README-д багтсан.

## Шинэ ажлын талбар

- Цайвар дэвсгэр, оюу ногоон тэмдэглэгээтэй зургаан ангиллын хэрэгслийн мөр.
- Зүүн талын давхаргын мод, цооног хайлт, огтлолын тохиргоо.
- Төвийн гурван хэмжээст/огтлол/төлөвлөгөөний камерын шилжилт.
- Доод хэсгийн бодит блок загвар ба цооногийн хүснэгт; хоосон нягт/чулуулгийн утгыг зохиохгүй.
- Баруун талын локал хиймэл оюуны туслах, шууд заавар, локал төслийн хураангуй.
- Жижиг дэлгэцэд хэрэгслийн мөр хэвтээ гүйлгэх боломжтой.

## Оруулсан боломжууд

- Collar/Survey/Assay/Lithology импорт, CSV баганын загвар, CRS, coverage ба QA/QC.
- Эргэлттэй блок загвар, төв/олон цэгийн үнэлгээ, анизотроп кригинг, top-cut, хөрш ба цооногийн хязгаар.
- Ойролцоо sub-block ангилал, хагарлын хавтгайн зааг, RBF гадарга.
- Огтлол, давхаргын тохиргоо, холбоотой гурван хэмжээст сонголт; Excel/STL болон байгууллагын SQL унших урсгал.
- Замын налуу ба тээврийн цикл, хүчин чадалтай MILP schedule, тусдаа pit optimizer.
- Программ ашиглах, тохируулах, алдаа засахад зориулсан local хиймэл оюуны туслах. Модель зааврын сэдэв сонгоно; харагдах алхмууд программын шалгасан заавраас гарна.

## 7 хоногийн лиценз

Туршилтыг хэрэглэгч өөрөө эхлүүлснээс хойш 168 цаг тоолно. Хугацаа дуусахад хадгалсан төсөл устахгүй; идэвхжүүлэх цонх гарч нээлттэй төслөө хадгалж болно. Төхөөрөмжид холбосон Ed25519 гарын үсэгтэй `.rainylic` файл шалгана. Арилжааны нийтийн түлхүүрийг эзэмшигч тохируулж дахин build хийх шаардлагатай; энэ build-д түлхүүр байхгүй. Offline trial нь серверийн хамгаалалт биш. Дэлгэрэнгүйг `LICENSING.mn.md`-ээс уншина.

## Шалгалтын баримт

Тест, desktop smoke, бодит local модель, EXE багцлах, суулгах, суулгасан EXE нээх шалгалтыг тухайн 1.0.0-rc.1 build дээр ажиллуулна. Бодит commit, run ID, файл бүрийн hash-ийг `release-manifest.json`-д оруулна. Өмнөх 0.5.0 build-ийн үр дүнг 1.0.0-rc.1-ийн баталгаа гэж орлуулахгүй.

CI шалгалт нь бүх бодит Windows/GPU төхөөрөмжийг шалгасан гэсэн үг биш.

## Нийтлэхээс өмнө мэдэх зүйл

- Суулгагч одоогоор тоон гарын үсэггүй. Hash нь файл өөрчлөгдөөгүйг шалгана; хэвлэн нийтлэгчийн гарын үсгийг орлохгүй.
- Программын өөрийн түгээлтийн лиценз, ашиглах гэрээ, арилжааны нийтийн түлхүүрийг эзэмшигч эцэслэх шаардлагатай.
- RAINYMINE 2026 зургийн ажлын талбарын бүтэц, цайвар/оюу ногоон өнгө, зургаан ангилал, давхаргын мод, төвийн харагдац, доод хүснэгт, баруун туслах хэрэгжсэн. Эхлэх дэлгэцийн artwork багцлагдсан; постерын уурхайн фото ба чулуун texture нь геологийн бодит өгөгдөл биш. Зарим техникийн диалог англи талбартай хэвээр.
- Sub-block/fault/зам/оновчлолын инженерийн хязгаарыг `KNOWN_ISSUES.mn.md`, README ба MICROMINE_SCOPE-д уншина.
- Бодит ордын хараат бус баталгаажуулалт, байгууллагын SQL серверийн acceptance, бодит Windows/GPU матриц хүлээгдсэн.

Энэ release нь draft бөгөөд нийтэд автоматаар хэвлэгдэхгүй. Эзэмшигч release checklist-ийг хянаж дуусгасны дараа нийтэлнэ.
