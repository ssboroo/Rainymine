# RAINYMINE 0.7.0 — суулгах, эхлэх заавар

## 1. Тохирох багцаа сонгох

- Ердийн суулгалт: `Rainymine-0.7.0-Setup-x64.exe`.
- Суулгахгүй ашиглах: `Rainymine-0.7.0-Windows-x64.zip`.
- Моделийг дахин татахгүй, оффлайн ашиглах: `Rainymine-0.7.0-AI-Offline-x64.zip`.

EXE багцад Python, Ollama эсвэл API key тусад нь хэрэггүй. Ердийн багцын AI модель анх татахад интернэт хэрэгтэй. Байгууллагын SQL холболт ашиглавал сервер болон тохирох ODBC driver тусдаа шаардлагатай.

## 2. Таталтаа шалгах

`SHA256SUMS.txt`-ийг хамт татна. PowerShell-д жишээ нь:

```powershell
Get-FileHash .\Rainymine-0.7.0-Setup-x64.exe -Algorithm SHA256
```

Гарсан утгыг checksum файл дахь яг ижил нэртэй файлын утгатай харьцуулна. Зөрвөл файлыг ажиллуулахгүй, дахин татаж шалгана. Hash нь тоон гарын үсэг биш.

## 3. Суулгах эсвэл задлах

Суулгагчийг нээгээд хавтас/товчлолын сонголтуудаа тохируулна. Суулгалт тухайн хэрэглэгчийн LocalAppData/Programs/Rainymine дотор хийгдэнэ.

Зөөврийн хувилбарт ZIP-ийг **бүхлээр нь** богино, бичих эрхтэй хавтаст задална. EXE-г ганцааранг нь хуулж болохгүй; ZIP дотроос шууд ажиллуулахгүй. Задласан хавтасны `Rainymine.exe`-г нээнэ.

## 4. Эхний төсөл

Зохиомол ЖИШЭЭ төсөл нээгдэнэ. Камер, давхарга, огтлолыг эхлээд үүгээр туршина. Өөрийн өгөгдөлд Төсөл → Шинэ, дараа нь Collar → Survey → Assay/Lithology импортлоно. CRS-ийг шалгаж, `.rmine` файлд хадгална. Бодит ордын файлаа эхлээд тусдаа хуулбарлана.

## 5. Хиймэл оюуны туслах

3D хэрэгслүүд → Local AI Туслах. Ердийн багцад «Анх тохируулах» дарж 1.28 GB моделийг нэг удаа татна. Offline багцад модель аль хэдийн хамт байна. Эхний асуулт дээр модель ачаалж RAM хэрэглэнэ. «Зогсоох / RAM чөлөөлөх» нь model process-ийг хаана.

Жишээ: «CSV импортын алдааг яаж засах вэ?». Туслах зөвхөн программын ажиллагааны заавар өгнө; төсөл өөрчлөхгүй, shell команд ажиллуулахгүй. Модельгүй үед зааврын жагсаалтыг шууд ашиглаж болно.

## 6. Хар/хоосон цонх

Задласан багцын `Rainymine-Software.bat`, эсвэл Start цэсний CPU rendering хувилбарыг нээнэ. `software-rendering` хавтсыг бүрэн хадгална. Системийн DLL-ийг гараар сольж болохгүй. Асуудал үлдвэл `SUPPORT_TEMPLATE.mn.md`-г бөглөнө.

## 7. Шинэчлэх, буцаах, устгах

Шинэчлэхээс өмнө `.rmine`, autosave болон хэрэгтэй импортын эх файлаа тусдаа хуулна. Хуучин portable хавтсыг шинэ хувилбараар давхарлан задлахын оронд шинэ хавтас ашиглана. Суулгагчийн upgrade/uninstall ажиллагааг бодит төхөөрөмж дээрх release checklist-ээр шалгана.

Windows → Settings → Apps-оос RAINYMINE-ийг устгана. Хэрэглэгчийн model cache, төслийн файлуудыг автоматаар устгасан гэж үзэхгүй; хэрэгтэй эсэхийг шалгаж байж тусад нь цэвэрлэнэ. Хуучин хувилбар руу буцахдаа нөөцлөсөн төслийн хуулбараа ашиглана.

## Туршилтын лиценз

Эхний нээлтээр 7 хоногийн туршилтаа эхлүүлнэ. Дуусах хугацаа болон төхөөрөмжийн дугаар «Лиценз» цэсэнд байна. Хугацаа дуусахад төсөл устахгүй. `LICENSING.mn.md`-ийг уншина уу. Арилжааны түлхүүрийг эзэмшигч хараахан тохируулаагүй.
